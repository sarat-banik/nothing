# My Website

A clean, modern starter website built with plain HTML, CSS, and JavaScript — no build tools required.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Main page (nav, hero, about, services, contact, footer) |
| `style.css` | Responsive styles with CSS custom properties |
| `script.js` | Mobile nav toggle + contact form validation |

## Getting Started

Open `index.html` in any browser, or serve the folder with any static file server:

```bash
npx serve .
# or
python3 -m http.server
```

## Customising

- Edit the text in `index.html` to reflect your content.
- Adjust colours and fonts in the `:root` block at the top of `style.css`.
- To handle contact-form submissions for real, replace the placeholder in `script.js` with a call to your backend or a service like [Formspree](https://formspree.io).
